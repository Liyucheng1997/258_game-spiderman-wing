# 蜘蛛侠:暮色摆荡 🕸️ v2

基于 Three.js 的第三人称蜘蛛侠摆荡游戏。黄昏的曼哈顿式城市里荡蛛丝、墙跑、击落无人机、挑战光环赛道。
所有模型与纹理均为代码程序化生成,无任何外部美术资源。

## 运行

需要本地静态服务器(ES Module 不能用 file:// 直接打开):

```bash
npx -y serve -l 8249 .
```

浏览器访问 http://localhost:8249 (推荐 Chrome / Edge)。`/viewer.html` 是模型查看器(可旋转查看角色各姿态、无人机、车辆、街道道具)。

## 操作

| 按键 | 功能 |
|---|---|
| 鼠标 | 视角 |
| W A S D / Shift | 移动 / 疾跑,空中操控,摆荡泵力 |
| 按住左键 | 发射蛛丝摆荡,松开脱手飞出(高速脱手自动空翻 +特技分) |
| 右键 / E | 蛛丝飞跃:朝准星急冲;锁定无人机时直接飞踢击毁 |
| F / 中键 | 蛛网弹:自动瞄准,命中缠住无人机(3 发击毁) |
| 空格 | 跳跃 / 二段跳;墙跑中蹬墙跳 |
| 贴墙按住 W | 沿墙向上冲刺,到楼顶自动翻越 |
| R | 放弃赛道挑战 |
| Esc | 暂停 |

## 玩法

- **蛛网令牌 ×40**:金色蛛网徽章,一半在楼顶,一半悬浮在街道上空
- **无人机 ×12**:发现你后会绕飞并用激光射击(眼睛闪烁 + 警报声为开火预警)。飞踢、高速撞击、蛛网弹均可击落
- **赛道挑战**:广场上的青色光柱,进入后倒计时,依次穿过 14 个光环,最佳成绩本地保存
- **超级英雄落地**:高速落地时单膝跪地 + 震屏 + 尘土
- **连击**:5 秒内连续得分倍率递增;完成全部令牌与无人机 +5000 分并显示结算
- 左下角小地图:令牌(金)、无人机(红)、下一个光环 / 赛道入口(青)

## 技术要点

- `js/spiderman.js`:**骨骼蒙皮角色**。躯干/手臂/腿为超椭圆截面放样(Loft)+ 高斯肌肉凸起(胸肌、腹肌、背阔肌、三角肌、二头肌、小腿肚…),`SkinnedMesh` 双骨骼权重过渡,关节无缝。战衣纹理逐像素绘制:胸口放射蛛网 + 下垂环线、背部红色大蜘蛛、蓝色侧片与六边形微纹理、红靴 V 形边;高度图转法线贴图,蛛网线呈凸起质感;`MeshPhysicalMaterial` 布料 sheen。头部为雕刻过的球体(下颌、鼻梁、眉弓、颧骨),面罩蛛网以面部为极点放射,白色镜片为从头部网格抽取并凸起的独立网格(清漆高光)。五指手套(每指三节,含"发射蛛丝"手势),九种程序化姿态
- `js/city.js` + `js/citytex.js`:13×13 街区城市。五类立面(玻璃幕墙 ×3 色、砖墙 ×3 色、装饰艺术石材、现代带窗、底商)各含颜色/发光/法线/粗糙度金属度贴图;退台塔楼、檐口、腰线、女儿墙、楼梯间、空调机组、木制水塔、天线尖顶与航空灯、屋顶广告牌、消防梯、彩色雨篷、竖排霓虹招牌;中央广场喷泉与钢制地球仪;公园;海滨护岸与栏杆、水面、远景天际线与悬索桥。几何按材质+分块合并(`js/geo.js`),保持少量 draw call
- `js/props.js`:全部 InstancedMesh —— 路灯与地面光斑、按相位切换的红绿灯、行道树/公园树、长椅、消防栓;轿车/出租车/SUV/公交车(挤出车身轮廓)车流,遵守红绿灯并跟车
- `js/drone.js`:车削机身、装甲环、四个涵道旋翼(转动)、传感器眼、双管激光炮、航行灯
- `js/sky.js`:黄昏天空着色器(渐变、太阳光晕、星星、fbm 云层),并用 PMREM 生成环境贴图供玻璃幕墙/车漆反射
- `js/main.js`:钟摆蛛丝物理、墙跑、AABB 碰撞、无人机 AI(视线检测/绕飞/预判射击)、赛道、小地图;后期:MSAA + UnrealBloom + 速度径向模糊/暗角/受伤红晕 + OutputPass(ACES)
- `js/audio.js`:WebAudio 全合成音效
