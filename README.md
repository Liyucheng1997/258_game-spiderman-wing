# 蜘蛛侠:暮色摆荡 🕸️

基于 Three.js 的第三人称蜘蛛侠摆荡游戏。在黄昏的摩天楼群之间荡蛛丝、收集令牌、撞毁无人机。

## 运行

需要本地静态服务器(ES Module 不能用 file:// 直接打开):

```bash
npx -y serve -l 8249 .
```

然后浏览器访问 http://localhost:8249 (推荐 Chrome / Edge)。

## 操作

| 按键 | 功能 |
|---|---|
| 鼠标 | 视角 |
| W A S D | 移动 / 空中操控 / 摆荡泵力 |
| 按住左键 | 发射蛛丝摆荡,松开脱手飞出(带加速) |
| 右键 / E | 蛛丝飞跃:朝准星急冲,可撞毁无人机 |
| 空格 | 跳跃 / 二段跳(墙边可蹬墙跳) |
| Shift | 疾跑 |
| Esc | 暂停 |

## 玩法

- **蛛网令牌 ×40**:金色八面体,散布在街道上空与楼顶,收集 +100 分
- **无人机 ×12**:靠近会追击、撞你掉血;以高速(>60 km/h)撞击或用蛛丝飞跃冲刺可撞毁,+250 分
- **连击**:5 秒内连续得分,倍率最高 ×3
- 被打倒扣 200 分回广场重生;完成全部目标 +5000 分

## 技术要点

- 纯 Three.js(CDN importmap,无构建步骤),全部模型与纹理程序化生成
- `js/spiderman.js`:关节层级角色建模(蛛网 canvas 纹理、大眼、胸口蜘蛛徽标),六种程序化姿态动画
- `js/city.js`:13×13 街区程序化城市——渐变天空着色器、霓虹窗发光贴图、公园、水塔天线、街灯、云
- `js/main.js`:钟摆式蛛丝物理(绳长约束+切向泵力+自动收绳)、AABB 建筑碰撞、追击 AI、连击计分、UnrealBloom 泛光、速度感 FOV
- `js/audio.js`:WebAudio 全合成音效(蛛丝 thwip、风声随速度、爆炸、收集音)
